# 📚 E-commerce Book Data Scraping and Analysis

## 📌 Overview
This project is a Python-based web scraping and data analysis project that extracts book information from an e-commerce website and performs exploratory data analysis using visualizations.

The project demonstrates practical implementation of:
- Web Scraping using BeautifulSoup
- Data Cleaning & Processing using Pandas
- Data Visualization using Matplotlib
- CSV File Handling

This project is ideal for beginners in Data Analytics and Python Automation.

---

# 🚀 Features

✅ Scraped 100+ book records from an e-commerce website  
✅ Extracted:
- Book Title
- Price
- Rating
- Availability Status

✅ Stored data into CSV format  
✅ Performed data analysis using Pandas  
✅ Generated visualizations using Matplotlib:
- 📊 Bar Chart
- 📈 Histogram
- 🥧 Pie Chart
