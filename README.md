# E-commerce Book Data Scraping and Analysis

## Overview
This project uses Python for web scraping and data analysis on e-commerce book data.

## Features
- Scraped 100+ book records
- Extracted prices, ratings, and availability
- Stored data in CSV format
- Created visualizations using matplotlib

## Technologies Used
- Python
- BeautifulSoup
- Pandas
- Matplotlib

## Files Included
- book_scraper.py
- books_data.csv

## Output
- Data analysis
- Bar chart
- Histogram
- Pie chart
